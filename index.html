Who is Dan Peter Etembe?

Understanding the background, mindset, leadership credentials, and ambition driving Dan Peter Etembe.

Dan Peter Etembe is a Nigerian student, solo developer, and technology enthusiast based in Lagos, Nigeria, with roots in Wanikade, Yala Local Government Area of Cross River State. Built upon a foundation of discipline, academic rigor, and natural curiosity, he combines analytical thinking with creative problem-solving.

His technological journey is self-driven. Interested in software engineering, web technologies, and progressive web apps, Dan approaches digital building not just as code, but as a discipline of planning, critical thinking, and structural execution.

⚡ Quick Supabase Database Table Setup (SQL Script)

Run this SQL script in your Supabase SQL Editor to create the posts and projects tables with public read/write access:

-- Create Blog Posts Table
CREATE TABLE IF NOT EXISTS public.posts (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  slug TEXT UNIQUE NOT NULL,
  category TEXT NOT NULL,
  excerpt TEXT,
  content TEXT,
  date TEXT,
  "readTime" TEXT,
  author TEXT,
  status TEXT DEFAULT 'published'
);

-- Create Projects Table
CREATE TABLE IF NOT EXISTS public.projects (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT,
  status TEXT,
  techs JSONB,
  role TEXT,
  "liveUrl" TEXT,
  "githubUrl" TEXT
);

-- Enable RLS & Allow Access
ALTER TABLE public.posts ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.projects ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read/write for posts" ON public.posts FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Allow public read/write for projects" ON public.projects FOR ALL USING (true) WITH CHECK (true);
